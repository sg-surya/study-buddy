01 / 06 · THE PROBLEM

Chatbots answer confidently even when your notes do not.

What: students revise from 2–5 page PDFs; generic bots answer from memory — learners can't tell supported vs invented.

Why it matters: wrong confidence before exams; no trace back to the page; no feedback on mistakes.

Proof: same questions → SUPPORTED-with-page vs NOT_FOUND on leph101.pdf. Today: ChatGPT-style chat + manual self-quiz — neither grounds in your material.

02 / 06 · PROPOSED SOLUTION

Upload notes → Ask → See proof → Quiz.

Flow: embed + retrieve top chunks → Gemma 4 cites → code verifies every quote is a real substring.

Features: page-tagged evidence + jump highlight · NOT_FOUND guard · real-notes quiz · meaning-based grading.

Impact: traceable in seconds · zero invented citations by construction · runs offline.

03 / 06 · TARGET USERS

Built for the night-before-exam student.

Primary: college students revising 2–5 pages. Need: "is this really in my notes?", practice Qs, honest feedback.

Secondary: judges verify via evidence + scores; teachers see misconceptions. Start: leph101 / photosynthesis; pilot = judges.

04 / 06 · AI COMPONENT

Gemma 4 reasons. Code verifies.

Model: google/gemma-4-e2b local via LM Studio :1234 · embeddings nomic-embed · Google AI Studio fallback. Open-weight, offline, private, strong JSON-mode.

AI does: grounded Q&A + quiz gen + grading + simplification. Safeguards: substring citation gate → forced NOT_FOUND · blank-answer fail · 0.72 / 0.55 thresholds.
